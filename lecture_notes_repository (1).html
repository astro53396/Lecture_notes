How to Publish on GitHub Pages

Step 1: Create GitHub Repo

Go to github.com/new. Name it class-vault or whatever you like. Make it Public and check "Add a README file".

Step 2: Upload index.html

Save this page's code as index.html. In your repo, click Add file > Upload files, drag index.html, and click Commit changes.

Step 3: Enable Pages

Go to Settings > Pages. Under Source, choose Deploy from a branch. Select branch main and click Save.

Step 4: Share Link with Friends!

Wait ~1 minute. You'll get a live link like https://yourusername.github.io/class-vault/. Share it in your group chat!
